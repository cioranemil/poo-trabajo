\section{Parte 1: Notas de Estudiantes}
Para esta primera parte armamos una ventana que pide cinco notas. Después de ingresarlas, el programa calcula el promedio, la desviación estándar y nos dice cuál fue la mayor y la menor nota de todas.

\textbf{Cosas extra que le pusimos para que no falle:}
\begin{itemize}
 \item Manejo de errores por si el usuario mete letras en vez de números por accidente.
 \item Nos aseguramos de que no se pueda calcular nada si dejaron algún espacio en blanco.
\end{itemize}

\subsection{Casos de Uso}
A continuación, se describen las interacciones principales que el usuario (o el sistema) puede realizar dentro de la aplicación de notas.

\textbf{Caso de Uso 1: Calcular Estadísticas de Notas}
\begin{itemize}
    \item \textbf{Actor principal:} Usuario.
    \item \textbf{Precondición:} La ventana de Notas debe estar abierta.
    \item \textbf{Flujo:} El usuario escribe las 5 notas requeridas en las cajas de texto y presiona el botón \textit{Calcular}. El sistema recibe los datos, realiza las operaciones matemáticas correspondientes y muestra el promedio, la desviación y los valores mayor/menor en pantalla.
\end{itemize}

\textbf{Caso de Uso 2: Validar Campos Vacíos}
\begin{itemize}
    \item \textbf{Actor principal:} Sistema.
    \item \textbf{Flujo Alternativo:} Si el usuario presiona \textit{Calcular} pero olvidó rellenar alguna de las notas, el sistema detiene el proceso matemático y muestra una ventana emergente de alerta para avisarle que todos los campos son obligatorios.
\end{itemize}

\textbf{Caso de Uso 3: Manejo de Formato Incorrecto}
\begin{itemize}
    \item \textbf{Actor principal:} Sistema.
    \item \textbf{Flujo Alternativo:} Si el usuario introduce accidentalmente texto no numérico (como letras o caracteres especiales), el bloque \textit{try-catch} intercepta el error. El sistema evita cerrarse inesperadamente y despliega un cuadro de diálogo rojo notificando el fallo de formato.
\end{itemize}

\textbf{Caso de Uso 4: Reiniciar Interfaz}
\begin{itemize}
    \item \textbf{Actor principal:} Usuario.
    \item \textbf{Flujo:} Tras realizar un cálculo o equivocarse, el usuario pulsa el botón \textit{Limpiar}. El sistema vacía inmediatamente todos los \textit{JTextField} y restablece los resultados visuales a cero para iniciar una nueva consulta.
\end{itemize}

\subsection{Cómo funciona por detrás}
\begin{itemize}
    \item \textbf{Cálculo:} Cuando metes las notas y le das a calcular, el código lee los textos, los convierte a números y llama a la clase Notas para hacer las matemáticas.
    \item \textbf{Reinicio:} Con el botón Limpiar se borran todos los campos de texto para poder hacer otro cálculo rápido.
    \item \textbf{Protección:} Le pusimos un bloque \textit{try-catch} para atrapar los \textit{NumberFormatException} y evitar que la app se caiga.
\end{itemize}


\section{Parte 2: Cálculo de Figuras Geométricas}
En esta segunda parte hicimos un programa para sacar el volumen y la superficie de cinco figuras tridimensionales: Cilindro, Esfera, Pirámide, Cubo y Prisma. Utilizamos herencia, donde todas las figuras concretas heredan sus datos principales de una superclase genérica.

\subsection{Casos de Uso}
A continuación, los casos de uso para la herramienta de cálculo geométrico:

\textbf{Caso de Uso 1: Seleccionar Figura a Calcular}
\begin{itemize}
    \item \textbf{Actor principal:} Usuario.
    \item \textbf{Flujo:} El sistema despliega el menú principal con cinco botones correspondientes a cada figura geométrica. El usuario selecciona la figura de la cual desea conocer las propiedades (ej. Cubo), y el sistema abre la ventana específica asociada a esa figura.
\end{itemize}

\textbf{Caso de Uso 2: Procesar Dimensiones Geométricas}
\begin{itemize}
    \item \textbf{Actor principal:} Usuario.
    \item \textbf{Precondición:} Estar dentro de la ventana de una figura específica.
    \item \textbf{Flujo:} El usuario digita los valores solicitados (como radio, altura o lados) y oprime \textit{Calcular}. El sistema crea el objeto correspondiente, aplica la herencia de la superclase y retorna el volumen y la superficie en pantalla.
\end{itemize}

\textbf{Caso de Uso 3: Excepción por Datos Erróneos}
\begin{itemize}
    \item \textbf{Actor principal:} Sistema.
    \item \textbf{Flujo Alternativo:} Al igual que en la calculadora de notas, el sistema verifica que las dimensiones ingresadas por el usuario sean dígitos válidos. Si el campo está vacío o contiene letras, detiene el proceso y emite una alerta.
\end{itemize}
