# Actividad 3 - Programación Orientada a Objetos

Este repositorio contiene la solución a los ejercicios de la **Actividad 3** del curso de Programación Orientada a Objetos.

## Contenido del Proyecto
El proyecto está estructurado mediante una interfaz gráfica desarrollada en Java Swing y cuenta con un **Menú Principal** centralizado que permite acceder a dos módulos distintos:

1. **Sistema de Evaluación Estudiantil (Notas):** Permite el ingreso de cinco calificaciones numéricas para un estudiante. Realiza validaciones para asegurar que todos los campos estén diligenciados y que correspondan a números válidos. Tras la validación, calcula de forma inmediata el promedio aritmético, la desviación estándar y los valores máximos y mínimos.
2. **Calculadora de Sólidos Geométricos (Figuras):** Cuenta con una ventana que actúa como submenú para calcular propiedades espaciales (volumen y superficie) de tres figuras específicas: Cilindro, Esfera y Pirámide. Emplea los conceptos de herencia y polimorfismo.

## Instrucciones de Ejecución

Para iniciar el programa y ver la interfaz interactiva, puedes ejecutar el archivo `.jar` ya compilado que se encuentra en la raíz del proyecto.

Abre una terminal o consola de comandos en esta carpeta y ejecuta:
```bash
java -jar Actividad_3_Menu.jar
```

Una vez que se abra la aplicación:
1. Verás el menú principal ("Seleccione una Actividad").
2. Haz clic en "3.1: Sistema de Notas" o "3.2: Sólidos Geométricos".
3. Al terminar de usar una actividad, puedes cerrar su respectiva ventana (usando la "X") y el menú principal seguirá abierto para que elijas otra opción.
4. Para cerrar completamente la aplicación, cierra la ventana del Menú Principal.
